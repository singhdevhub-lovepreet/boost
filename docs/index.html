How it works

Stays out of the way

It watches silently. When branch context changes, it reacts.

01

Work normally

Open shells, cd between directories. Boost hooks into your shell and monitors pane context in the background.

~/project (main) $
02

Switch branches

cd into another worktree. Boost detects the branch change through shell hooks.

$ cd ../project-feature
03

Auto-regroup

Panes reflow into per-branch columns. Labels and colors update. Zero manual work.
