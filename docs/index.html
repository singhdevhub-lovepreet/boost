How It Works

How It Works

It stays out of the way until branch context changes.

01

Work normally

Open shells, cd between worktrees. Boost watches silently.

~/project (main) $

02

Switch branches

cd into another worktree. Boost detects the branch change.

$ cd ../project-feature

03

Auto-regroup

Panes reflow into branch columns. Labels and colors update.

feature-login feature-login
bugfix-nav

Installation

Up and Running in 30 Seconds

Drop it into your shell, source the hook, and start grouping panes automatically.

git clone https://github.com/singhdevhub-lovepreet/boost.git
cd boost/tmux-authadjust
./install.sh
1. Add ~/.local/bin to PATH 2. Source the shell hook 3. Press prefix + g in tmux
